# ИИ-Оракул — настройка «магического» голоса

Как устроены промпты и как усилить Велеса (и других богов).

---

## Архитектура промпта

Оракул собирает **несколько system-сообщений** + одно user-сообщение:

```
┌─────────────────────────────────────┐
│ 1. РОЛЬ + мифологический канон      │  ← god-oracle-profiles.ts
├─────────────────────────────────────┤
│ 2. ГОЛОС + образы                   │
├─────────────────────────────────────┤
│ 3. СТРУКТУРА ответа (5 секций)     │
├─────────────────────────────────────┤
│ 4. Глоссарий: Явь / Навь / Правь    │
├─────────────────────────────────────┤
│ 5. ЗАПРЕТЫ (taboos)                 │
└─────────────────────────────────────┘
         +
┌─────────────────────────────────────┐
│ USER: странник, подношение,         │
│ намерение, время суток, тон          │
└─────────────────────────────────────┘
```

Сборка: `src/ai/prompts/oracle-prompt.builder.ts`  
Профили богов: `src/ai/prompts/god-oracle-profiles.ts`

## Профиль Велеса (что уже заложено)

| Слой | Содержание |
|------|------------|
| **Канон** | Знать и Ведать, три мира, Велесова книга, медведь/ворон/змей, противостояние Перуну |
| **Голос** | Шёпот в сумерках, загадки, без прямых да/нет |
| **Структура** | Эпиграф → Знамение → Пророчество → Наставление → Благословение |
| **Контекст** | Чистота подношения меняет глубину ответа |
| **Время** | Сумерки/ночь усиливают «навский» тон |

Температура для Велеса: **0.92** (образнее, чем у Перуна 0.78).

## Переменные окружения

| Переменная | Эффект |
|------------|--------|
| `OPENAI_MODEL` | `gpt-4o` — богаче стиль; `gpt-4o-mini` — быстрее и дешевле |
| `OPENAI_MAX_TOKENS` | Длина ответа (рекомендуется **900+** для 5 секций) |
| `OPENAI_ORACLE_TEMPERATURE` | Базовая «магичность» (0.85–0.95) |

## Как усилить ещё (идеи)

### 1. Few-shot примеры

Добавь в `god-oracle-profiles.ts` поле `examples: [{ intention, response }]` и вставляй в system prompt 1–2 эталонных пророчества Велеса.

### 2. RAG по текстам

Подключи короткие выдержки из «Повести временных лет», Буслаева, Рыбакова — как отдельный system-блок «ИСТОЧНИКИ» (без галлюцинаций фактов).

### 3. Руны и знаки в ответе

В `responseFormat` попроси иногда вставлять руну-намёк: ᛉ (Algiz — защита), ᛈ (Pertho — тайна).

### 4. Сезоны и праздники

В `oracle-prompt.builder.ts` → `timeOfDayHint()` расширить до календаря: Купала, Масленица, Радуница.

### 5. Память диалога

Хранить последние 2–3 вопроса странника в сессии — Велес «помнит» тропу.

### 6. Постобработка

Проверять, что ответ не содержит «как ИИ», «я языковая модель» — иначе retry с усиленным taboo.

## Добавить профиль нового бога

1. Открой `src/ai/prompts/god-oracle-profiles.ts`
2. Добавь ключ `godId` (как в `SLAVIC_GODS`)
3. Заполни: `lore`, `voiceRules`, `imagery`, `responseFormat`, `temperature`
4. Перезапусти API — builder подхватит автоматически

Без профиля используется `DEFAULT_ORACLE_PROFILE`.
