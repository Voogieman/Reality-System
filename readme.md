# Reality System 🌄

Система управления реальностью
## Описание

Этот проект представляет собой Nest.js приложение для управления реальностью, включая взаимодействие с богами, выполнение ритуалов и поддержание баланса между мирами.

## Основные возможности

- **Пробуждение родовой крови** - активация наследственных сил
- **Контакт с богами** - взаимодействие со славянским пантеоном
- **Создание баланса** - управление равновесием между Светом и Тьмой
- **Выполнение ритуалов** - магические практики для воздействия на реальность

## Установка и запуск

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run start:dev

# Сборка проекта
npm run build

# Запуск в продакшене
npm run start:prod
